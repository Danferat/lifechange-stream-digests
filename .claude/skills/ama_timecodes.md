# Скилл: ama_timecodes

Генерирует проверенные таймкоды вопросов для АМА-записи и вопросный исходник для будущей АМА-выжимки.
Используется только когда пользователь выбрал режим `AMA-таймкоды`.

Новый вопрос в АМА начинается с момента его зачитывания вслух - это и есть нужный таймкод.

## Вызов

```
/ama_timecodes [stem]
```

---

## Шаг 1. Запросить скрины вопросов

Если скрины ещё не предоставлены — спросить:

> Скинь скрины вопросов из чата — по ним сделаю таймкоды

Ждать скрины. Это обязательный входной источник.

## Шаг 2. Подготовить вопросы

По скринам создать `{work_dir}/summary_outputs/{stem}_ama_questions.md`:

```text
- Полный текст первого вопроса
- Полный текст второго вопроса
```

Каждый вопрос - одна строка. Не сокращать формулировки: скрипт использует их для поиска.

## Шаг 3. Построить кандидаты по сырым сегментам

Запустить:

```bash
python3 scripts/build_ama_timecodes.py "{work_dir}" {stem} \
  "{work_dir}/summary_outputs/{stem}_ama_questions.md"
```

Скрипт читает `{stem}_segments.json`, а не `_summary_source.md`: его кандидаты привязаны к речевым сегментам, а не к четырёхминутным блокам.

## Шаг 4. Проверить начало чтения каждого вопроса

Прочитать `{stem}_ama_timecodes_candidates.md`, затем проверить соседние сегменты в `{stem}_segments.json`.

Таймкод должен стоять перед началом зачитывания вопроса. Если ведущий говорит «следующий вопрос», брать этот сегмент, а не сегмент с последними словами вопроса.

Создать `{stem}_ama_timecodes_review.md` с одной подтверждённой строкой на вопрос:

```text
MM:SS - короткая тема первого вопроса
MM:SS - короткая тема второго вопроса
```

## Шаг 5. Собрать финальные файлы

```bash
python3 scripts/build_ama_timecodes.py "{work_dir}" {stem} \
  "{work_dir}/summary_outputs/{stem}_ama_questions.md" \
  --review-file "{work_dir}/summary_outputs/{stem}_ama_timecodes_review.md"

python3 scripts/validate_outputs.py "{work_dir}" {stem} --check-ama
```

Это создаёт:

- `{stem}_ama_timecodes.md` - готовый список для публикации
- `{stem}_ama_source.md` - текст АМА, разбитый границами вопросов
- `{stem}_ama_timecodes.json` - проверенные границы для автоматической обработки

## Шаг 6. Вывести результат

Формат — простой список, одна строка на вопрос:

```
MM:SS - суть вопроса одной фразой
MM:SS - суть вопроса одной фразой
...
```

Правила строки с сутью:
- Одна короткая фраза, только тема вопроса
- Без объяснений и контекста
- Без точки в конце
- Дефис "-" вместо длинного тире "—"

В финальном отчёте указать количество вопросов, путь к `{stem}_ama_timecodes.md`, путь к `{stem}_ama_source.md` и `VALIDATION_OK`.
