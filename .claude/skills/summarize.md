# Скилл: summarize

Генерирует `summary_short.md` и `summary_intermediate_notes.md` из `summary_source.md`,
затем запускает build-скрипты и проверяет финальные артефакты.

Использовать при любой просьбе сделать выжимку, сводку, summary стрима в проекте
`<project-root>`.

## Вызов

```
/summarize [work_dir] [stem]
```

Аргументы опциональны — если не указаны, скилл сам находит цель.

---

## Шаг 1. Найти цель

Если `work_dir` и `stem` не указаны:

- Найти в `work/` все папки, где есть `groq_outputs/<stem>_summary_source.md`,
  но нет `summary_outputs/<stem>_summary_short.md`.
- Если одна такая папка — взять автоматически.
- Если несколько — спросить пользователя какую обрабатывать.
- Если таких папок нет — сообщить что все стримы уже обработаны.

## Шаг 2. Прочитать исходники

Прочитать оба файла:

- `{work_dir}/groq_outputs/{stem}_summary_source.md` — N строк сырой транскрибации
- `{work_dir}/groq_outputs/{stem}_meta.json` — взять `summary_source_lines` (это N)

Каждая строка source имеет формат: `HH:MM:SS  <сырой текст блока>`.

## Шаг 3. Сгенерировать summary_intermediate_notes.md

Записать в `{work_dir}/summary_outputs/{stem}_summary_intermediate_notes.md`.

Правила:
- Ровно N строк — по одной на каждый блок из source, в том же порядке
- Формат: `HH:MM:SS  Короткое описание` (тот же таймкод из source, два пробела)
- Описание: компактно, явная тема блока — что конкретно обсуждалось
- Без точки в конце строки
- Без markdown-маркеров, скобок, кавычек, эмодзи

## Шаг 4. Сгенерировать summary_short.md

Записать в `{work_dir}/summary_outputs/{stem}_summary_short.md`.

Правила формата:
- 19–24 строки (не меньше, не больше)
- Не более 4000 символов суммарно
- Каждая строка: `HH:MM:SS Глагол конкретика` (один пробел после таймкода)
- Таймкод берётся из source в точке смены ключевой темы
- Описание начинается с глагола (Разбираем, Показываем, Объясняем, Анонсируем, Переходим, Говорим...)
- Тезисы от первого лица множественного числа: «мы», не «автор» / «спикер»
- Без точки в конце строки
- Без markdown-маркеров, скобок, кавычек, эмодзи
- Объединять мелкие переходы в одну строку если они в одном смысловом кластере
- Выбирать значимые моменты, не дублировать каждый таймкод из source

## Шаг 5. Запустить build-скрипты

Выполнить последовательно из корня проекта:

```bash
python3 scripts/build_intermediate_digest.py "{work_dir}" {stem}
python3 scripts/build_final_digest.py "{work_dir}" {stem} --limit 12
python3 scripts/validate_outputs.py "{work_dir}" {stem} --check-final
```

## Шаг 6. Финальный отчёт

Вывести:
- Количество строк и символов в `summary_short.md`
- Пути к файлам для выгрузки (`_summary_short_with_links.md`, `_summary_with_links.md` если есть)
- Результат валидации (`VALIDATION_OK` или описание ошибки)
